# Working papers

The documents a business analyst and a project manager keep while the nine deliverables are built. **Tanmark Industries is fictional; every entry is illustrative.**

| # | Paper | What it answers |
|---|---|---|
| W1 | [Charter and scope, with a context diagram](W01-charter-and-scope.md) | What is in scope, and why? |
| W2 | [Stakeholder register and map](W02-stakeholders.md) | Who had to be won over? |
| W3 | [Elicitation log](W03-elicitation-log.md) | How were requirements gathered and confirmed? |
| W4 | [Data model and data dictionary](W04-data-model.md) | What does the business record, and which fields carry the rules? |
| W5 | [Non-functional requirements](W05-non-functional-requirements.md) | What must hold across the whole system, and how is it tested? |
| W6 | [Business rules and a decision table](W06-business-rules.md) | Which rules apply when, and which status combinations are legal? |
| W7 | [Interface: sales to accounting](W07-interface-sales-to-accounting.md) | Where one application's number becomes another's document |
| W8 | [Requirements traceability matrix](W08-traceability-matrix.md) | Which test proves which objective? (generated) |
| W9 | [Backlog and change requests](W09-backlog-and-changes.md) | What came first, and how was a change after sign-off handled? |
| W10 | [RAID log](W10-raid-log.md) | Risks, assumptions, issues and dependencies |
| W11 | [Business case](W11-business-case.md) | Why this option, and what it returns (generated) |
| W12 | [Communications and lessons learned](W12-communications-and-lessons.md) | Who heard what, when, and what changes next time |
| W13 | [Release roadmap and dependencies](W13-release-roadmap.md) | What ships when, what each release waits on, and the dependency that slipped |

**Read these four first**, the ones that show the analysis rather than the form: **W6** (the status decision table),
**W7** (where a discount could be applied twice), **W3** (two requests the analysis changed) and **W9** (each change
request assessed and routed to its owner).

The nine deliverables they support are listed in the repository's [README](../README.md).
